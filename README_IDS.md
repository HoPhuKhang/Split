# Split App - Integrated Design System (IDS)

Ứng dụng di động được thiết kế theo hệ thống tiêu chuẩn **Split Design System**, tập trung vào sự tối giản, nhất quán và trải nghiệm người dùng mượt mà trên nền tảng Android.

## 🎨 1. Hệ thống màu sắc (Colors)
- **Paper (`#FBF7F0`)**: Màu nền chính của ứng dụng.
- **Card (`#FFFFFF`)**: Màu nền cho các thẻ (card) và khung nhập liệu.
- **Mint Strong (`#0A7A57`)**: Màu chủ đạo (Primary) thương hiệu.
- **Ink (`#2A2622`)**: Màu chữ chính hiển thị nội dung.

## 🧩 2. Tài nguyên giao diện (Drawables)
- `bg_card`: Thẻ bo góc 16dp, viền mảnh tiêu chuẩn.
- `bg_input`: Ô nhập liệu bo góc 12dp với viền nổi bật.
- `bg_hint` / `bg_warn`: Banner thông báo gợi ý và cảnh báo.
- `bg_pill`: Nút bấm dạng viên thuốc bo tròn.

## 🛠 3. Công nghệ sử dụng
- **Language**: Kotlin / XML Layouts
- **Architecture**: Material 3 (DayNight NoActionBar)
- **Version Control**: Git
