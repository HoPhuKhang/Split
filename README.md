# Split — 회식 정산 앱

> 사용자인터페이스 팀 프로젝트 · 대학생 회식 1차·2차 정산을 3분 안에

회식이 끝나면 누가 얼마를 보내야 하는지 계산하느라 분위기가 깨집니다.
Split은 차수별로 누가 있었고, 누가 결제했고, 누가 무엇을 먹었는지만 입력하면
**송금 횟수가 가장 적은 정산 결과**를 보여 주고, 알림도 앱 이름으로 대신 보내 줍니다.

- 저장소: https://github.com/HoPhuKhang/Split
- 다운로드: [Releases → v1.0](https://github.com/HoPhuKhang/Split/releases) 의 `Split-v1.0.apk`

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 정산 방식 3가지 | 빠른 N분의 1 · 메뉴별 정산 · 회식 모드(1차, 2차…) |
| 차수별 입력 | 차수마다 참석자와 결제자를 따로 지정, 결제자를 고르기 전에는 메뉴 추가 불가 |
| 먹은 사람 지정 | 사람을 고르고 메뉴를 탭하거나, 메뉴를 사람에게 끌어다 놓기 |
| 오류 예방 | 그 차수에 없던 사람은 지정 불가, 배정 안 된 메뉴가 있으면 결과로 넘어가지 않음 |
| 송금 최소화 | 최대 n(n−1)/2번 주고받을 것을 n−1번 이하로 줄임 |
| 부드럽게 알리기 | 말투 3가지(친근하게·간단하게·정중하게), 내 이름이 아닌 Split 이름으로 전송, 여러 명에게 차례로 전송 |

## 화면 흐름

1. 모임 만들기 → 2. 정산 방식 선택 → 3. 금액·차수 입력 → 4. 먹은 사람 지정 → 5. 정산 결과 → 6. 부드럽게 알리기 → 7. 보냈어요

## 예시: 금요일 동아리 회식 (총 93,000원)

| | 결제 | 먹은 몫 | 결과 |
| --- | --- | --- | --- |
| 지훈 | 1차 58,000원 | 38,500원 | 19,500원 받음 |
| 민지 | 2차 35,000원 | 38,500원 | 지훈에게 3,500원 |
| 서연 (1차만) | 0원 | 16,000원 | 지훈에게 16,000원 |

서로 주고받으면 최대 3번이지만, Split은 **2번**으로 끝냅니다.

## 실행 방법

- APK: Releases에서 `Split-v1.0.apk`를 받아 안드로이드 폰(Android 7.0 이상)에 설치
- 소스: Android Studio에서 이 저장소를 열고 `app` 실행
- 단위 테스트: `./gradlew :app:testDebugUnitTest` (17개)
